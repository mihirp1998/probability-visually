# Probability, visually

Interactive, visual probability & statistics notes for quant and ML interviews — a static site (no build step) using KaTeX and a small vanilla-JS plotting library (`assets/lib.js`).

Based on [Alisa Liu's math notes](https://alisawuffles.notion.site/math-notes), expanded with intuition, interactive widgets, quizzes, and corrections.

Run locally: `python3 -m http.server` in this folder and open http://localhost:8000.
